GOLDFLINCH
A manager for names on local multimedia databases.

BASIC DESCRIPTION
The renaming process is based on PlexMediaServer's and renaming for tv series.
The program follows 2 main ideas: 
1.: Each name must fully contain the identification and important information of the file it corresponds to
2.: All names must imitate the SERIES sequence for programing clarity.

SERIES
"SeriesName - EpisodeCode - EpisodeName - SDQ - IMDBid - SERIES" 
=> Where SDQ stands for Sub Dub Quality, with the format [S:][][], and EpisodeCode follows "S(season number)E(episode number)"

MOVIES
"MovieName - S01E01 - MovieName - SDQ - IMDBid - MOVIES"

MUSIC
"Artist - S(Disk)E(song number in disk) - SongName - SpotifyID - MUSIC"

BOOKS
"Writer - Edition - Title - SDQ - ISBN - BOOKS"

AUDIOBOOKS
"Writer - Edition - Title - SDQ - ISBN - AUDIOBOOKS"

YT
"Channel - UploadDate - VideoTitle - SDK - ytID - YT"
