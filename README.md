GOLDFLINCH
A manager for names on local multimedia databases.
The renaming process is based on PlexMediaServer's and renaming for tv series:
"SeriesName - EpisodeCode - EpisodeName - SDQ - IMDBid - Series" 
=> Where SDQ stands for Sub Dub Quality, with the format [S:][][], and EpisodeCode follows "S(season number)E(episode number)"
